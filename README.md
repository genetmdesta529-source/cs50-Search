# Google Search Clone

A front-end implementation of Google Search, Google Image Search, and Google Advanced Search, created as part of Harvard University's CS50 Web Programming with Python and JavaScript course.

## 📌 Project Overview

This project recreates the Google Search interface using HTML and CSS.

Users can:
- Perform a standard Google search.
- Search for images using Google Image Search.
- Perform an advanced Google search using different search filters.
- Navigate between the search pages.

The project uses HTML forms to send search queries directly to Google's search engine.

## ✨ Features

### 1. Google Search
- Search for information using Google's search engine.
- Includes a Google Search button.
- Includes an "I'm Feeling Lucky" button.
- Search input is automatically focused when the page loads.

### 2. Google Image Search
- Search for images using Google Image Search.
- Uses the `tbm=isch` parameter to request image results.

### 3. Google Advanced Search
- Search using all of these words.
- Search for an exact word or phrase.
- Search using any of these words.
- Exclude specific words from the search.

### 4. Navigation
- Navigate between the main search page, image search page, and advanced search page.

### 5. Responsive Design
- Search fields adapt to smaller screen sizes.
- The layout uses CSS Flexbox for alignment.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Search URL Parameters
- CSS Flexbox

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Enter a search query and select a search option.

You can also use the Live Server extension in VS Code to run the project locally.
